# E-Commerce Order Management System


A responsive e-commerce website built from scratch using **HTML, CSS, and JavaScript**, featuring a product storefront, shopping experience, and Telegram-based order notifications.

## 🌐 Live Demo

[View Live Website](https://hevaibhav.github.io/ecommerce-order-management/)

## ✨ Features

- Responsive e-commerce storefront
- Product browsing
- Shopping cart functionality
- Order placement
- Telegram order notifications
- Mobile-friendly UI
- Clean and lightweight frontend
- No frontend framework

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Telegram Bot API
- GitHub Pages

## 🔔 Telegram Order Notifications

Customer orders are sent to Telegram so the store owner can receive order information in real time.

## ⚠️ Security Note

This is a frontend-only project. A Telegram bot token should **never be exposed in client-side JavaScript or committed to a public repository**.

For production use, Telegram API requests should be handled through a backend or serverless function, with the bot token stored securely as an environment variable.

If a bot token has previously been exposed publicly, it should be regenerated through **BotFather**.
